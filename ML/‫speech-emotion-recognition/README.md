## Augmented Dataset

The augmented ShEMO dataset produced by `shemo-augmentation.ipynb`
(9,464 samples: original + noise/reverb/codec-augmented versions)
is available on Kaggle:

https://www.kaggle.com/datasets/ftmjfr/shemo-augmented

Derived from [ShEMO](https://github.com/pariajm/ShEMO) (Mohamad Nezami et al., 2019),
used here for academic purposes.

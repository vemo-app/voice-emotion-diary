# VEMO

**VEMO — AI-Powered Voice Diary with Emotion Recognition and Empathetic Response Generation**

> This project was developed as a **Bachelor's thesis project**.

## Overview

Emotion recognition and analysis from speech and text is an important application of artificial intelligence in the field of **Human–Computer Interaction (HCI)**. Since emotions play an important role in people's everyday experiences, an intelligent system that can not only record personal memories but also identify the emotions expressed in them and analyze emotional changes over time can provide a more personalized and meaningful experience.

**VEMO** is an AI-powered **voice diary application** designed and developed as a Bachelor's thesis project. It allows users to record and manage their daily memories, recognize emotions from both speech and text, generate empathetic responses, and analyze emotional trends over time.

## How VEMO Works

A user can record a daily memory as a voice note. The audio is first converted into text using **Whisper Large V3**. The resulting transcription is then processed by a **Large Language Model (LLM)** to correct common transcription errors and better handle characteristics of conversational speech.

The corrected text and the original audio signal are then processed by separate emotion recognition models to identify four target emotions:

* **Anger**
* **Happiness**
* **Sadness**
* **Neutral**

The detected emotions, together with the memory content, are provided to an LLM to generate a **personalized and empathetic response** for the user.

VEMO also analyzes the user's emotional data across **daily, weekly, and monthly periods**. By comparing these time periods, the system provides insights into changes and trends in the user's emotional state over time.

## Machine Learning Models

### Speech Emotion Recognition

The speech emotion recognition model was developed and optimized using:

* A pretrained speech emotion recognition model trained on the **ShEMO** dataset
* Augmented speech data derived from ShEMO
* Real-world speech samples collected by the project team

The final model combines a **Wav2Vec2-based speech representation** with selected acoustic features and a **Logistic Regression classifier**.

The model achieved **74% accuracy** on an independent test set.

The trained model components are available on Hugging Face.

### Text Emotion Recognition

The text emotion recognition model was developed using a pretrained language model and further fine-tuned using:

* Data generated by the project team
* The **ArmanEmo** dataset

The final model achieved **88% accuracy** on the evaluation data.

### Speech-to-Text

VEMO uses **Whisper Large V3** for speech recognition.

The Speech-to-Text component was evaluated using **Word Error Rate (WER)** and achieved a WER of **34.28%**.

## Dataset and Evaluation

Overall, approximately:

* **10,000 speech samples**
* **8,000 text samples**

were used for training and evaluating the machine learning components of the system.

The real-world speech samples collected by the project team are **not publicly released** due to privacy considerations.

### `Backend`

Contains the server-side implementation of VEMO, including:

* API endpoints
* Database models and migrations
* Application services
* Background workers
* Machine learning model integration
* Media storage
* Authentication and configuration

The `ml_models/` directory contains the expected structure for locally available model artifacts. Large model files are stored separately rather than committed to the Git repository.

### `Frontend`

Contains the client-side application used to interact with VEMO, including the user interface for:

* Recording and managing memories
* Viewing memory content and emotions
* Receiving empathetic responses
* Exploring emotional trends and analyses

### `Speech_Emotion_Recognition`

Contains the experiments and development process for VEMO's speech emotion recognition model, including:

* Pretrained baseline evaluation
* Data augmentation experiments
* Fine-tuning experiments
* Deep feature extraction
* Acoustic feature analysis
* Final model development and evaluation

### `Text_Emotion_Recognition`

Contains the experiments and development process for VEMO's text emotion recognition model.
